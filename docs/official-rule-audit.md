# 官方规则核验报告

核验日期：2026-08-11。

## 核验结论

- 武将库：28/28 名已核验。
- 技能枚举：47/47 个已纳入防漏清单，并由专项测试或既有行为测试覆盖。
- 卡牌/装备枚举：44/44 种已纳入防漏清单，并由专项测试或既有行为测试覆盖。
- 精确牌堆：标准包 108 张、军争篇 52 张、项目扩展木牛流马 1 张，共 161 张；花色、点数和实体牌 ID 由牌表测试固定。
- 自动化门禁：`official-rules-audit.test.ts` 会在新增技能或卡牌枚举但未同步审计清单时失败。

## 本轮修复的官方规则差异

1. 桃可指定任意已受伤角色；无中生有可指定包括自己在内的任意角色。
2. 火攻和铁索连环可以指定自己；手中最后一张火攻使用后自己已无手牌，因此不能以自己为目标。
3. 借刀杀人只有在持刀者攻击范围内存在合法杀目标时才能使用；被迫杀的目标由锦囊使用者选择，也可以是锦囊使用者本人；没有杀仍须交出武器而非随机交牌。
4. 强袭按攻击范围而非固定距离 1 选目标，且木牛流马下的武器牌不能作为“弃置一张武器牌”的费用。
5. 青釭剑、古锭刀恢复为锁定效果；寒冰剑、贯石斧、方天画戟和麒麟弓均改为由发动者精确选牌/选目标。
6. 丈八蛇矛允许精确选择两张手牌/粮，并可在南蛮、决斗、激将等需要打出杀的场景响应；混色实体牌生成的虚拟杀为无色。
7. 酒的加伤能正确跟随普通杀、属性杀、武圣、龙胆、丈八蛇矛、激将和借刀杀人产生的杀，并在声明下一张杀时消耗。
8. 流离和英魂不能用木牛流马下的粮支付弃牌费用；流离会先选合法转移目标，再提交弃置牌。
9. 木牛流马不再提供不符合牌面的“主动取回粮”或独立移交动作，只能在置粮后立即选择是否连同全部粮移交。
10. 闪电绕过所有已有闪电或其他非法目标后回到原角色判定区，不进入弃牌堆。

## 明确保留的项目边界

- 为避免使用者连续收到“是否无懈自己的锦囊”提示，项目按既定交互规则跳过锦囊使用者对原锦囊的第一轮无懈询问；一旦其他角色打出无懈，使用者仍可无懈反制。这是有意保留的交互差异。
- 酒按项目约定采用简化目标规则：出牌阶段只能对自己使用；这与规则集3.0允许指定“包括你在内的一名角色”不同。
- 武将不自动升级版本。例如黄月英采用旧标准/国标集智、奇才，陆逊采用经典谦逊/连营，曹仁采用 2017 界限突破版本。以后若升级武将，必须作为独立规则变更同步修改实现、测试和本文档。
- 当前牌堆是“标准 108 + 军争 52 + 木牛流马 1”的项目牌表，不声称等同某一盒实体扩展的原始装盒方式。
- 官方规则的完整事件优先级远大于当前武将库。本报告只证明当前 28 名武将与 44 种卡牌在项目可达场景中的行为，不代表尚未加入的武将技能组合已经实现。
